# WorkSphere — Gestion du personnel

Application web pour organiser le personnel sur un plan d’étage, répartir les employés par zone et consulter leurs informations.

## Fonctionnalités

- Ajouter un employé avec ses coordonnées, son rôle et ses expériences
- Afficher les employés qui ne sont pas encore affectés à une zone
- Affecter les employés selon les rôles acceptés dans les différentes zones
- Consulter et gérer les profils des employés
- Rechercher et filtrer les employés affichés
- Utiliser l’interface de gestion et son panneau latéral

Les données de l’application sont gérées dans le navigateur. Elles ne sont pas enregistrées dans une base de données.

## Technologies

- HTML
- CSS
- JavaScript

## Lancement

Aucune installation de dépendances n’est nécessaire. Clonez le dépôt et ouvrez `index.html` dans un navigateur :

```bash
git clone https://github.com/yassminejabal/bref-setnense-croisi.git
cd bref-setnense-croisi
```

## Structure du projet

- `index.html` : structure de l’application
- `css.css` : styles de l’interface
- `javascript.js` : interactions et logique d’affectation
- `img/` : images et autres ressources graphiques
